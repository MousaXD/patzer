## New verified failure

The analyzer used the condition `!chess.isGameOver() && !validPositionScore(result)` when deciding whether to accept engine evidence. This wrongly treats `chess.js`'s broad `isGameOver()` predicate as permission to accept an **unknown** numeric evaluation. `isGameOver()` can be true for a **claimable** threefold repetition even when the PGN is explicitly unfinished, or for a checkmated terminal position whose engine response is incomplete. `normalizeEval(null, null, ...)` then turns absent evidence into **0cp**, silently writing a fabricated draw-like score into the move timeline.

### Reproductions (fail before, pass after)

1. **Unclaimed repetition:** Synthetic unfinished PGN `1. Nf3 Nf6 2. Ng1 Ng8 3. Nf3 Nf6 4. Ng1 Ng8 *` with a fake engine returning a missing evaluation on the final position. Prior code incorrectly completed the review with the last `eval_after_cp` as `0`. After the fix, it throws `engine_invalid_score` and closes the engine. An explicitly **claimed** draw still uses the prior history-aware 0cp correction.
2. **Checkmate terminal:** Synthetic `1. f3 e5 2. g4 Qh4# 0-1`, with the final fake-engine response lacking both centipawn and mate score. The old terminal exemption could silently call the final evaluation 0cp; after the fix the analysis fails closed. A factual local `mate: 0` is still a valid terminal score.
3. **Ad-hoc position endpoint:** Fake `POST /position` on a checkmated FEN with no score previously returned HTTP **200** and risked caching invalid terminal evidence. The new isolated Hono route regression first failed; after tightening the guard it returns **503** and does not cache the failure. A subsequent factual `mate: 0` response returns 200 and is cached as expected.

### Narrow implementation

- `server/src/routes/analyze.ts`: Always require `validPositionScore()` before using an engine result on **both full PGN and ad-hoc position paths**, including game-over positions. The existing synthetic claimed-draw result has `cp: 0`, so it passes naturally. No scoring formula or conversion coefficient changed.
- `server/test/analysis-agent-pgn-lifecycle.test.ts`: Two fail-closed synthetic PGN regressions.
- `server/test/analysis-agent-position-score.test.ts`: Mocked DB, config, auth and engine with no active application, private games, SQLite, external HTTP or session secret. Checks error status, no cache of invalid evidence, and acceptance of factual terminal mate-zero.
