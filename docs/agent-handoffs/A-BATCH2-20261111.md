## Remaining caveats

1. The hostile benchmark branch `agent/review-benchmark-20261111` reports 14 self-authored fixtures, 42 legal game plies and 7 detected bad controls, but **0 sealed holdout**; that evidence applies to its checker/baseline, **not** an independent validation of this branch's new source or model accuracy. No cross-system MAE, bias, learning gain, or Chess.com-parity improvement is claimed.
2. Remote score semantics and depth still depend on the provider's claimed White POV and budget; converting a negative value does not independently prove the remote provider's truth. Same-position high-depth stability, tablebases and larger curated datasets remain unmeasured.
3. FEN-only remote and local calls cannot reconstruct *earlier unclaimed repetition history* or distinguish a claimed draw by agreement from all possible chess states. The final-claimed-draw correction is intentionally narrow; general repetition-sensitive evaluation needs a versioned history-bearing engine request contract.
4. The ad-hoc position/variation caches key by **requested** backend. If a **first** hosted call fails and falls back entirely to local, that successful result can be cached under the hosted key. A future evidence DTO or cache contract should include actual effective engine identity/version and settings, coordinated with integrator and UI consumers. No shared response/schema was silently changed here.
5. `accuracy_white`/`accuracy_black` remain numeric `0` if no eligible moves due to the existing API contract. The UI should present **unavailable / insufficient evidence**, not a misleading zero-percent performance claim. This needs coordination with Agent C rather than an unapproved shared DTO migration.
6. A midgame hosted outage now returns an explicit failure instead of silently switching engines. The UI can offer a **recompute from the beginning with local Stockfish** action in a separate, opt-in/approved feature; the backend does not secretly restart or save partial analysis.
7. No change to classifier coefficients, the v9/v10 aggregation formula, opening thresholds, DB structure, or the historical scoring-version constant; no private/production benchmarks or new external dependencies.
